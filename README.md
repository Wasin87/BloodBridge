# 📖 Overview

BloodBridge is a modern AI-powered blood donation management platform designed to connect blood donors with patients quickly and efficiently.

The platform allows users to:

- Register as blood donors
- Search blood donors by location and blood group
- Create emergency blood requests
- Manage donation history
- View personal dashboard
- Authenticate securely
- Access responsive UI across all devices

The project focuses on making blood donation faster, smarter, and more accessible.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Wasin87/BloodBridge.git
```

Go to project directory

```bash
cd BloodBridge
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production

```bash
npm run preview
```

---

# ⚙ Environment Variables

Create a `.env` file and add:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
